# Multi-Agent Financial Research System

An AI-powered financial research platform that uses
specialized AI agents to analyze company financial documents.

## Project Overview

The system aims to:

- Process financial documents.
- Extract financial metrics and ratios.
- Detect financial red flags.
- Compare multiple companies.
- Answer financial research questions with citations.
- Generate analyst-style PDF reports.

## Technology Stack

### Backend
- Python
- FastAPI

### Frontend
- React
- Vite
- JavaScript

### AI & Data
- LangGraph
- ChromaDB
- Sentence Transformers
